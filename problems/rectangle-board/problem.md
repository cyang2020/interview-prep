# 题面

## 题目

- 写一个 width 列、height 行的板子，往上贴矩形。矩形可以互相压住，后贴的在上面。每贴一张发一个编号，从 1 开始递增，撕掉的编号不回收。x 是列、y 是行，都从 0 开始。
- addRectangle(x1, y1, x2, y2)：贴一张，左上角 (x1, y1)、右下角 (x2, y2)，边界上的格子也算盖住。返回新编号。
- removeRectangle(rectangleId)：按编号把整张撕掉，返回 true；编号没发过或已经撕过，返回 false，板子不变。
- getAt(x, y)：返回盖住这格、还在板上、最上面那张的编号；一张都没有返回 -1。
- 第一问：只做上面三个方法。板子最大 50×50，一块板最多 2000 次调用。
- 第二问：加 undo()：撤销最近一次改动，返回 true，没有可撤的返回 false。成功的 add、成功的 remove 各算一次改动（撕掉被完全压住、画面没变的也算），失败的 remove、getAt、undo 本身不算；撤销 add 后编号不回退。
- 第三问：加 removeAt(x, y)：把这格最上面那张整张撕掉，返回它的编号；这格空的返回 -1、不算改动。成功一次在历史里和 removeRectangle 一样算一条。
- 第四问：加 batchRemove(x, y)：把盖住这格的所有矩形（包括被压住的）整张撕掉，返回撕掉的张数；没有返回 0、不算改动。整批算一条，一次 undo 全部放回。

## 要问清楚的地方

- 有没有"把某张挪到最上面"这类改层次的操作。
- undo 之后要不要 redo。
- batchRemove 返回的张数算不算已经撕掉的。
- 一块板会不会贴满 2000 张全屏矩形，每次查询能不能线性扫。
