# 第三问：D 天恢复，答案是最后感染日加 D

## 这一问要做什么

- 写 time_to_stable_state(grid, D)：多一个参数 D，感染格满 D 天就变 2，不再传染。每天先处理到期，再传染。
- 问题换了：返回网格里一个感染格都没有了是第几天，没被传到的健康格可以留着；一开始就没有感染返回 0。

## 核心思路

- 新接口 time_to_stable_state(grid, D)：返回网格里没有感染格的那一天，有健康格留着不算错。D<1 抛 ValueError。
- 规则：第 t 天感染的格子第 t+D 天开始时变 2 永久免疫；每天先处理到期，再传播。
- _infection_days 只加一处：D == 1 时初始化完直接返回，不进传播循环。来源第 1 天一开始就到期，来不及传给谁。
- D≥2 时首次感染日和前两问完全一样：第 t 天感染的格子第 t+1 天还活着，一次就把所有健康邻居感染完，之后活多久不会再产生新的首次感染。
- time_to_stable_state 取 infection_day 的最大值 last_infection_day，加 D 就是答案；最大值是 -1 表示没有感染，返回 0。不调 _full_infection_days。
- 复杂度 O(RC)，和 D 无关：D=1000000 的 [[1, 0, 0]] 直接算出 1000002。

## 思考与反问

- 到期和传播谁先？按先到期再传播。[[1, 0]]、D=1 返回 1；反过来右格会在第 1 天被感染，答案变 2。这决定了代码里 D == 1 提前返回那一行。
- 恢复后是永久免疫，还是回到健康能再感染？按永久免疫。能再感染的话一格会有多个感染日，infection_day 只写一次的做法不成立。
- "稳定"是没有感染格，还是全图不再变化？按没有感染格。[[1, 2, 0]]、D=2 返回 2，右边健康格永远健康不影响。
- 为什么不逐天模拟到没有感染：每天扫全图是 O(D × RC)，D=1000000 跑不完；最后到期日 = 最后感染日 + D，一步算出来。
- 追问"格子出队了但还没恢复，不用留在 queue 里吗"：不用。它第一次传播已经把能感染的邻居都感染了，什么时候到期只影响答案里的 +D。
- 追问"感染要多个邻居再叠恢复，还能这样算吗"：不能。"一次传播就完事"依赖"一个邻居就能感染"，所以第四问的阈值版明确不带恢复。

## 测试要点

- test_no_infection_is_already_stable：[[0, 2, 0]] 和 [] 没有感染，返回 0。
- test_recovery_happens_before_spread：[[1, 0, 0]]、D=1 返回 1，来源到期前没传出去。
- test_last_infection_waits_its_own_lifetime：[[1, 0, 0]]、D=2 返回 4；[[1, 1]]、D=4 返回 4。
- test_large_lifetime_does_not_require_daily_scans：D=1000000 返回 1000002，不能逐天算。
- test_recovery_with_an_unreachable_healthy_cell：[[1, 2, 0]]、D=2 返回 2，健康格留着不影响。
- test_recovery_matches_literal_days：100 个随机 2×3 网格，和独立逐天模拟 _simulate_until_done 的结束日对照。
- test_recovery_rejects_zero_lifetime：D=0 抛 ValueError。

## 更多说明

### [[1, 0, 0]]、D=2 每天长什么样

| 天 | 先到期 | 当天新感染 | 日末状态 |
|---|---|---|---|
| 0 | 无 | (0, 0) 初始来源 | [1, 0, 0] |
| 1 | 无 | (0, 1) | [1, 1, 0] |
| 2 | (0, 0) 变 2 | (0, 2) | [2, 1, 1] |
| 3 | (0, 1) 变 2 | 无 | [2, 2, 1] |
| 4 | (0, 2) 变 2 | 无 | [2, 2, 2] |

首次感染日仍是 [0, 1, 2]，最大值 2 加 D=2 得 4。solution.py 不逐天构造这些状态，只算日期。

### D=1 为什么返回 1 不是 2

| 天 | 传播前状态 | 新感染 | 日末状态 |
|---|---|---|---|
| 0 | [1, 0] | 初始来源 | [1, 0] |
| 1 | [2, 0]，来源已到期 | 无 | [2, 0] |

### 三个入口对同一输入的答案

| 输入 | time_to_full_infection | time_to_stable_state，D=2 |
|---|---|---|
| [[0]] | -1 | 0 |
| [[1]] | 0 | 2 |
| [[1, 2, 0]] | -1 | 2 |

前两问问"健康格有没有全感染"，第三问问"感染有没有全结束"，停止条件不同，不能共用 _full_infection_days。
