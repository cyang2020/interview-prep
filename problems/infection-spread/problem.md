# 题面

## 题目

- 给一块矩形网格 grid，每格一个数字：0 健康、1 感染、2 永久免疫、3 死亡。每天所有感染格同时把上下左右四个邻居里的健康格传染，今天刚被传染的格子明天才开始往外传。写几个函数直接算出结果，不用真的一天天等。
- 第一问 time_to_full_infection(grid)：网格里只有 0 和 1，返回所有健康格都被传染完要几天；有健康格永远传不到返回 -1，一开始就没有健康格返回 0。
- 第二问 time_to_full_infection_with_immunity(grid)：网格里多了 2，2 永远不被传染、也不往外传，其他同第一问。
- 第三问 time_to_stable_state(grid, D)：感染格满 D 天就变成 2，不再传染。返回网格里一个感染格都没有了是第几天，没传到的健康格可以留着；一开始就没有感染返回 0。
- 第四问阈值版 time_to_full_infection_threshold(grid, K)：健康格要同时挨着至少 K 个感染格才会被传染，感染后不恢复。返回全部传染完要几天，传不到返回 -1。
- 第四问死亡版 time_to_end_with_deaths(grid, D, K)：传染还是挨着一个就够；刚被传染那天挨着至少 K 个感染格的，满 D 天时死掉变 3 而不是变 2。返回 (最后一个感染格结束的那天, 死了几个)。
- 第五问 minimum_deaths(grid, D, K)：规则同死亡版，但每天你可以选一整行或一整列烧掉，也可以不烧，烧到的格子都算死。返回所有烧法里最少的总死亡数，烧死加病死，每格只算一次。

## 要问清楚的地方

- 相邻是上下左右四个，还是连对角线八个。这里按四个。
- 到期（恢复或死亡）是在当天传染之前还是之后。这里按之前，所以 D=1 的感染格一个都传不出去。
- 第五问每天必须烧，还是可以不烧。原题是必须烧，这里主线按可以不烧。
- 烧死的格子算不算进要最小化的死亡数。这里按算，免疫格被烧也算。
- 已经整条全死的行或列能不能再烧一次、要不要花钱。这里按能、不花钱。
