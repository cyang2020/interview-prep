# 题面

## 题目

- 写一个记录"谁关注了谁"的数据结构：每条关注带时间，能查过去任意时刻两个人是不是关注关系，还能给人推荐"朋友的朋友"。
- update(A, B, t)：A 从 t 时刻起关注 B。加 following=False 表示 A 从 t 时刻起取消关注 B。
- check(A, B, t)：返回 t 时刻 A 是否关注 B，True 或 False。
- recommend(A, t, k=None)：t 时刻给 A 推荐"A 关注的人也在关注的人"。中间人多的排前面；中间人一样多，指向他的关注边更新的排前面。返回前 k 个，k 不给就返回全部。
- 第一问：只做 update 和 check。t 可以是过去任意时刻，不只是现在。
- 第二问：加 recommend。只算 t 时刻还在的关注关系；A 自己和 A 在 t 时刻已经关注的人不推荐。

## 要问清楚的地方

- update 是否按时间顺序到达。
- 有没有取消关注（方法名叫 update 不叫 follow，像是有）。t 恰好等于关注时刻算不算关注。
- 同一对人同一时刻两条 update，哪条算。
- 推荐并列时"最近"指指向候选人的边，还是 A 出去的边。
- 自己关注自己怎么处理。
