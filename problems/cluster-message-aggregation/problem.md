# 题面

## 题目

- 写一棵树上每台机器都跑的同一段程序。机器只能和自己的父亲、孩子发消息；每台机器知道自己的 node_id、parent_id（根是 "-1"）和 children 列表。客户端给根发 "count" 或 "topology"，根最后要打印出整棵树的节点总数或整棵树的结构。
- receive_message(from_id, message)：收到一条消息时系统自动调它，from_id 是谁发的，message 是一段字符串。要你写。from_id 等于 "-1" 表示是外部客户端发的，只有根会收到。
- send_async_message(target_id, message, from_id)：给父亲或某个孩子发一段字符串，发出去就返回，没有返回值。已经实现好，直接调。
- 第一问：收到 "count"，根打印节点总数。题面例子的 7 节点树打印 7。
- 第二问：收到 "topology"，根打印整棵树：叶子打印自己的 id，非叶子打印 id(孩子1,孩子2,...)，孩子按 children 顺序。例子打印 1(2(4),3(5,6(7)))。
- 第三问：把两种操作合并成一套流程，再加一种操作时只写"怎么合并孩子的结果"。
- 第四问：多个请求同时在跑，比如两个 "count" 前后紧挨着到，两个都要打印对。
- 第五问：消息会丢、机器会挂。丢了要重发，重复到的消息不能算两遍，某个孩子一直没回音要报出来是谁。
- 第六问：receive_message 会被多个线程同时调，要加锁；一万个节点连成一条链也要能跑。

## 要问清楚的地方

- 同一台机器的 receive_message 是一次处理一条，还是会被同时调。
- 消息会不会丢、会不会乱序。
- 会不会有多个客户端请求同时在跑。
- 节点 id 会不会含冒号这类特殊字符，这决定消息里能不能用冒号做分隔。
- 题面里 fromId 一处写 String 一处写 int，按哪个。
