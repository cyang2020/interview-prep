# 第一问：最大得分

## 这一问要做什么

- 写 max_score(board, p, K)：从 (0, p) 出发，每步走到下一行相邻三格之一，或者往正下方跳两行（最多 K 次），到最后一行停下，返回踩过格子分数之和的最大值。
- 跳过去的那一格不算踩过，不加分。格子值可以是负数。

## 核心思路

- 状态是 (i, j, k)：走到第 i 行第 j 列，恰好用了 k 次特殊跳。dp[i][j][k] 存这个状态的最大得分，到不了存 NEG。
- 为什么要带 k：到同一格的两条路线，一条跳过 1 次、一条跳过 0 次，后面还能不能再跳不一样，不能合并成一个值。
- 为什么是"恰好 k 次"不是"最多 k 次"：恰好的状态互不重叠，最后在底行对所有 k 取最大就是"最多 K 次"的答案；第三问数路线条数时这一点决定不会重复计数。
- 反推前驱：对每个 (i, j, k)，按 MOVES 里的四种走法算出 (pi, pj, pk) = (i - di, j - dj, k - dk)，越界或 pk < 0 的跳过，cand = dp[pi][pj][pk] + board[i][j]，取最大。
- 跳过的格子不加分，体现在特殊跳那条转移只加 board[i][j]，不碰 board[i-1][j]。
- kmax = min(K, (n - 1) // 2)：每次跳过 2 行，从第 0 行到第 n-1 行最多跳这么多次，表的第三维不随 K 无限长。
- 答案是底行 dp[n-1][j][k] 对所有 j、k 取最大。只有一行时循环不跑，答案就是 board[0][p]。
- 复杂度：状态 n·m·(kmax+1)，每个看 4 个前驱；n = m = 200、kmax = 100 时约 1600 万次比较。

## 思考与反问

- 到不了的状态存什么？按 NEG（负无穷）。存 0 的话，[[-10, 0], [-10, -10]] 从 (0,0) 出发，(0,1) 到不了却是 0，(1,0) 会从它转移得到 -10，正确答案是 -20。
- 倒数第二行能不能跳？按不能，跳出棋盘不算到底行。代码里只给存在的行填表，第 n 行不存在，自然没有从第 n-2 行跳过去的状态。
- 只有一行怎么办？按起点就是终点，返回 board[0][p]。
- 跳是不是只能正下方？按题面只有 (i+2, j)。斜着跳的话 MOVES 里加两项即可，其余不改。
- 正推还是反推？按反推（站在 (i, j, k) 看前驱）。正推要在前驱处往后写四个目标，第二、三问加 parent 和 count 时反推只改一处比较。
- K 比行数还大会怎样？不加 kmax 封顶，K = 200 时第三维开 201 层，一半以上永远是 NEG，白花一倍时间和内存。

## 测试要点

- test_official_examples：三个官方例子 23、255、17。
- test_single_row_is_already_at_bottom：只有一行时返回起点自己的分。
- test_unreachable_cells_are_not_zero：到不了的格子不能当 0 用，全负棋盘答案是 -20 不是 -10。
- test_jump_cannot_overshoot_bottom：两行棋盘不能跳，必须踩第二行。
- test_jump_can_land_exactly_on_bottom：跳到底行是合法的。
- test_jump_budget_is_enforced：K = 0、1、2、99 四种预算下答案不同，且封顶后再加预算不变。
- test_jump_is_straight_down_only：不能斜着跳。
- test_matches_brute_force_on_random_boards：150 个随机小棋盘和暴力枚举的最大值一致。
- test_large_k_equals_capped_k：60 行棋盘 K = 60 和 K = 29 答案一样。

## 更多说明

### 用例子 2 走一遍

board = [[1, 5, 1], [-100, -100, -100], [1, 50, 1], [1, 1, 200]]，p = 1，K = 1。只列和答案有关的状态。

| 状态 (i, j, k) | 前驱 | 得分 |
|---|---|---|
| (0, 1, 0) | 起点 | 5 |
| (1, 0, 0)、(1, 1, 0)、(1, 2, 0) | (0, 1, 0) | -95 |
| (2, 1, 1) | (0, 1, 0) 跳过来 | 55 |
| (2, 1, 0) | 第 1 行任意一格 | -45 |
| (2, 2, 0) | (1, 1, 0) 或 (1, 2, 0) | -94 |
| (3, 2, 1) | (2, 1, 1) | 255 |
| (3, 2, 0) | (2, 1, 0) | 155 |

底行里最大的是 (3, 2, 1) 的 255。(2, 1, 1) 和 (2, 1, 0) 是同一格的两个状态，分开存才知道 55 这条已经没有跳的预算了。(3, 2, 1) 还有一个前驱是 (1, 2, 0) 跳过来，-95 + 200 = 105，比 255 小，没选上。

### dp 表的形状

dp 是 n 行、每行 m 列、每列 kmax + 1 个数。n = 4、m = 3、kmax = 1 时一共 24 个格子，起点那一格是 5，其余先全是 NEG，然后按 i 从 1 到 3 逐行填，每一行只依赖上面两行。
