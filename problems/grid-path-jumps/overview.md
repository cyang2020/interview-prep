# 整体思路

**一句话。** 状态是"走到哪一格、跳了几次"：dp[i][j][k] 存从起点到 (i, j) 恰好跳了 k 次的最大得分。第二问在每个状态旁边记它从哪来（parent），第三问记有几条路线能拿到这个最大值（count），第四问给状态加一位"走进这格那一步是不是严格上升"（c）。四问共用同一张表、同一个三重循环。

**四问是叠加关系。** 第一问定下表和转移；第二问每个状态多记一个 parent，不改转移；第三问每个状态多记一个 count，转移里多一个"打平相加"的分支；第四问改状态定义，三张表都多一维 c，转移里多算奖励。前三问的函数签名第四问只加默认参数 X=0、Y=0，老测试一行不改照样过。

## 转移

| 到达状态 | 来自 | 条件 | 得分 |
|---|---|---|---|
| (i, j, k) | (i-1, j-1, k) | j-1 ≥ 0 | 前驱得分 + board[i][j] |
| (i, j, k) | (i-1, j, k) | 总是 | 同上 |
| (i, j, k) | (i-1, j+1, k) | j+1 < M | 同上 |
| (i, j, k) | (i-2, j, k-1) | i ≥ 2 且 k ≥ 1 | 同上，跳过的 (i-1, j) 不加 |
| 到不了 | 四个前驱都是 NEG | | NEG |

第四问每个前驱再按前驱自己的 c 分成两种（pc = 0 或 1）：得分再加 X·[前驱值 == 当前值] + Y·[pc = 1 且 前驱值 < 当前值]，结果落到 c = [前驱值 < 当前值] 那一格。

## 数据结构

| 结构 | 存什么 | 回答什么问题 | 第几问出现 |
|---|---|---|---|
| dp[i][j][k] | 到 (i, j) 恰好跳 k 次的最大得分，到不了是 NEG | 这个状态最好能拿多少分 | 一 |
| MOVES | 四种走法的 (行偏移, 列偏移, 消耗跳数) | 枚举前驱时少写四段重复代码 | 一 |
| kmax | min(K, (N-1)//2) | 表的第三维开多长 | 一 |
| parent[i][j][k] | 取到最大值时的前驱状态三元组 | 最优路径的上一格是谁 | 二 |
| count[i][j][k] | 拿到 dp[i][j][k] 这个分的路线条数 | 有几条路线打到这个分 | 三 |
| 第四维 c | 走进这格那一步是否严格上升 | 下一格能不能拿 Y | 四 |

## 复杂度

| 问 | 状态数 | 每个状态的工作 | N=M=200、K=100 时 |
|---|---|---|---|
| 一、二、三 | N·M·(kmax+1)，kmax ≤ 100 | 看 4 个前驱 | 约 1600 万次比较 |
| 四 | 上面的 2 倍 | 看 4 个前驱 × 2 种 pc | 约 6400 万次 |

内存和状态数同阶，parent 表每个状态存一个元组，是最大的一张。纯 Python 跑满 200×200、K = 100 实测第一问约 5 秒、第四问约 30 秒，面试里说清这个数就够；要真跑满，按行用 numpy 向量化，或者换编译型语言。

## 面试节奏

- 前 3 分钟：先说清"跳过的格子不加分"和"只有一行、倒数第二行不能跳"这几条边界，再说状态为什么要带 k：不带 k 就不知道还剩几次跳可以用。
- 第 3-12 分钟：写第一问。先写 NEG 和 MOVES，再写 _fill 的三重循环和反推前驱，最后写底行取最大。写完先跑三个官方例子。
- 第 12-20 分钟：第二问。只加 parent 表和回溯，说明 who 为 None 就是起点或到不了。
- 第 20-30 分钟：第三问。重点说"恰好 k 次"而不是"最多 k 次"，以及打平要把所有前驱的 count 相加。
- 第 30-45 分钟：第四问。先口头推出"只需要记一位"，再把三张表加一维。
- 最后 10 分钟：写测试。优先这四个：到不了的格子不能当 0、跳不能出棋盘、打平计数、跳过的格子不参与奖励。

## 常见追问

| 追问 | 一句话答法 |
|---|---|
| 内存太大 | 第一问只用到上两行，dp 滚动只留 3 行；第二问要回溯，parent 可以只存走法编号 0 到 3 而不是三元组 |
| 不存 parent 也能回溯吗 | 可以：从底行往上反着填一张"从这格到底行还能拿多少"的表，然后从起点出发每步选能保持总分的走法 |
| K 很大 | kmax = min(K, (N-1)//2)，超过的预算用不上，表不会随 K 无限变大 |
| 为什么状态是恰好 k 次不是最多 k 次 | 恰好 k 次的状态两两不重叠，第三问的条数相加才不会重复；最多 k 次的话一条路线会在 k、k+1 里各被数一次 |
| 第三问条数会爆吗 | 每行最多 3 分支，200 行是 3^199 量级，Python 大整数直接存；别的语言要问取模 |
| 奖励窗口改成 4 格递增 | c 从 1 位变成"当前连续上升了几步，封顶 2"，3 个取值；窗口长 L 就存 min(连续上升步数, L-1) |
| X 或 Y 是负数 | 转移是加法取最大，不依赖正负，代码不用改 |
| 要能从任意起点出发 | 把第 0 行全部初始化成 board[0][j]，表的其他部分不变 |
| Python 跑不满 200×200×100 | 每一行对每个 k 做 numpy 的整行平移和取最大，内层两层循环没了，剩 N·kmax 次向量操作 |
