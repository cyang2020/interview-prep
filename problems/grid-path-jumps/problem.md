# 题面

## 题目

- 给一个 N 行 M 列的整数格子 board，每格一个分数，可能是负数。从第 0 行第 p 列出发，走到最后一行的任意一格，路上踩过的格子分数全加起来（起点和终点都算），要最大。
- 每一步只能往下：(i+1, j-1)、(i+1, j)、(i+1, j+1) 三种普通走法，或者 (i+2, j) 这种特殊跳。特殊跳最多用 K 次，跳过去的那格 (i+1, j) 不算踩过，不加分。
- max_score(board, p, K)：第一问，返回最大得分。
- best_path(board, p, K)：第二问，返回一条拿到最大得分的路径，格式 [[行, 列], ...]，从 [0, p] 开始、在底行结束。跳过的格子不出现在路径里。多条最优随便返回一条。
- count_best_paths(board, p, K)：第三问，返回拿到最大得分的路径有几条。坐标序列不同就算不同的路径。
- max_score(board, p, K, X, Y)：第四问，加两条奖励：路径里相邻两格值相等加 X；相邻三格值严格递增加 Y。每对、每个三格窗口各自算，窗口重叠也分别算。跳过的格子不参与奖励判断，跳前跳后两格算相邻。返回加了奖励后的最大得分。
- N、M 最大 200，K 最大 N，格子值在 -10^4 到 10^4，X、Y 在 0 到 10^4。

## 要问清楚的地方

- 只有一行时起点就是终点，是不是直接返回起点自己的分。
- 特殊跳能不能跳出棋盘：倒数第二行能不能跳。
- 第三问的条数要不要取模。Python 大整数不怕，别的语言要问。
- 第二问多条最优时按什么规则选，还是任意一条都行。
- X、Y 会不会是负数。
